## 🗂 Структура проекта

Каждая лабораторная работа размещена в своей директории:

- `lab1/misha` — Лабораторная работа №1 (C++, случайное блуждание частицы)
- `lab2/misha` — Лабораторная работа №2 (Python, клеточный автомат)
- `lab3/src`   — Лабораторная работа №3 (C++, движение электомагнитной волны в плоском волноводе)
- `lab4/misha` — Лабораторная работа №4 (C++ + Python, задача Блазиуса в погран слое)

Сборка C++-проектов производится с использованием CMake. Python-проекты используют виртуальное окружение и зависимости из `requirements.txt`.
